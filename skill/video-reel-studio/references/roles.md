# الأدوار — من يستلم ماذا

المشرف (إنت) مش بيوزّع أدوار بشكل درامي. الدور = **مسؤولية محددة + مخرج محدد + بوابة محددة**.
كل دور إما المشرف بيعمله بنفسه (الأغلب)، أو بيتسلّم لوكيل فرعي لما يكون الفحص **أحسن بذاكرة نظيفة**
(مراجعة بصرية، مراجعة عربية) أو عندما يكون العمل مستقلًا تمامًا (توليد مشاهد بالتوازي).

## جدول الأدوار

| الدور | المسؤولية | المخرج | البوابة |
|---|---|---|---|
| **المشرف** (أنت) | يقرأ الطلب، يكتب `brief.json`، يختار الوضع، يشغّل السكربتات بالترتيب، يقرأ النتائج، يقرر الإصلاح | `brief.json` + سجل التنفيذ | G0 |
| **المخطِّط** | يحوّل الطلب لجملة واحدة: الجمهور، الوعد، الطول، النبرة، الـ CTA، لقطات لا تُمس | قسم `plan` في `brief.json` | G0 |
| **المحرّر** | القص، التفريغ، تصحيح الكابشن، توقيت الكروت | `cut.json` + `caps.json` + `fixes.json` | G2, G3 |
| **المصمّم** | المشاهد، الحركة، الستايل، «ورا الشخص»، الطبقات | `compose.html` + `scenes*.js` + `behind.json` | G4 (معاينة) |
| **المدقّق العربي** (وكيل نظيف) | يقرأ كل كرت كابشن + كل نص على الشاشة ويحكم: أخطاء إملائية/لهجة/معنى مقلوب/أرقام | تقرير سطر لكل كرت | G3b |
| **المدقّق البصري** (وكيل نظيف) | يقرأ `sheet.jpg` + `audit-grid.jpg` والحواف والسيف زون والكفر | تقرير: مقبول / مشكلة + اللقطة | G4b, G6b |
| **المسلِّم** | الترميز، الماستر، الترجمة، الكفر، الحجم، تقرير التسليم | الملفات + `gates.md` | G5, G6 |

## متى تُسلّم لوكيل فرعي

سلّم بس لو فيه واحد من دول:

1. **الحكم البصري** — المشرف الذي صمّم المشهد هو أسوأ من يحكم عليه. وكيل نظيف يرى الصور أول مرة.
2. **الحكم اللغوي** — مراجعة العربية تحتاج قراءة بطيئة بلا سياق التصميم.
3. **العمل المتوازي** — كتابة مشهدين مستقلين لملفين مختلفين (لا يتشاركان ملف).

غير كده اعمله بنفسك. التسليم العشوائي بيحرق توكنز وبيضيّع القرار.

## قالب برومبت الوكيل

```
أنت [الدور]. اقرأ فقط: <مسارات الملفات>.
لا تعدّل أي ملف. لا تشغّل أي سكربت.
مهمتك: <سؤال واحد محدد>.
أعد الإجابة بهذا الشكل حصراً:
- الحكم: مقبول | مشكلة
- الدليل: <رقم اللقطة/السطر + ما رأيته>
- الإصلاح المقترح: <سطر واحد>
```

قاعدة: **الوكيل مش بيكتب ومش بيرسم.** بيقرأ ويحكم بس — عشان ما يفسدش شغلك من غير ما تدري.

## المشرف: قرارات لا تُفوَّض

- الوعد في أول 3 ثواني.
- أي تعديل على كلام المستخدم.
- حذف جملة كاملة.
- تغيير الستايل أو الألوان.
- الموافقة على تسليم فيه تحذير (warn) لم يُصلح.

## سجل التنفيذ

كل مرحلة تكتب سطرًا في `<work>/run.log`:

```
12:03 G2 cut.json 11 قطع · 71.6 ث · pass
12:07 G3 caps.json 33 كرت · pass
```

السجل ده هو اللي بتلخّصه للمستخدم في الآخر — مش ذاكرة المحادثة.
