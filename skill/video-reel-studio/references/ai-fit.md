# الملاءمة — على أي وكيل وموديل هتشتغل؟

السؤال الثامن (وبيلغي ترتيب الباقي): **مين اللي هيشغّل السكل؟** الإجابة مش للتسجيل، هي بتغيّر:
مسارات التثبيت، مين يعمل المراجعة البصرية، قد إيه المشاهد تتجرأ، وإزاي التفريغ الطويل يتقسّم.

تُحفظ في `brand.json` ← `ai`، وتتكتب في `<work>/ai.json` مع كل مشروع.

## 1) الوكيل (host) — يغيّر المسارات والأوامر

| الوكيل | مكان السكل | علامة التعرّف | ملاحظة |
|---|---|---|---|
| **OpenCode** | `.opencode/skills/` أو `~/.config/opencode/skills/` | `.opencode/` | الافتراضي — كل حاجة مجرّبة هنا |
| **Claude Code** | `~/.claude/skills/` | `.claude/` | المحرّك نفسه، بس أوامر `claude plugin` مختلفة |
| **Codex** | `~/.codex/skills/` | `.codex/` | يحتاج `AGENTS.md` بدل `SKILL.md` أو تحويل |
| **Cursor** | `.cursor/rules/*.mdc` | `.cursor/` | السكل يتحوّل لقاعدة، مش سكل |
| **Gemini CLI** | `~/.gemini/skills/` | `.gemini/` | `GEMINI.md` |

`preflight.py` بيشوف علامة المشروع ويقارنها باللي في `ai.json` — لو مختلف يطلع **warn** واضح
(مش fail، لأن المشروع ممكن يكون منقول).

## 2) الموديل — يغيّر جرأة التصميم ومين يراجع

| طبقة الموديل | أمثلة | المشاهد | المراجعة البصرية | الميزانية |
|---|---|---|---|---|
| **قوي + vision** | Opus/Sonnet, GPT-5 class, Gemini Pro | 6–8 مشاهد، لحظات عمق (3D، ورا الراس، طبقات) | وكيل فرعي يقرا `sheet.jpg` | عادي |
| **قوي بلا vision** | موديلات نصية كبيرة | 4–6 مشاهد، بلا قرارات بصرية دقيقة | المراجعة أرقام فقط (safe_check + midframes) + اطلب من المستخدم عين | عادي |
| **سريع/رخيص** | Flash/Mini/Haiku class | 3–5 مشاهد، أنماط مثبتة من `moves.md` بلا اختراع | أرقام فقط | قلّل المعاينات: ورقة واحدة، وكل بوابة مرة |
| **محمول/محلي** | Ollama, LM Studio | مشهدين + كابشن قوي | أرقام فقط | شغّل السكربتات وأعد النتائج، وانت تحكم |

**قاعدة الكلام:** لو الموديل مش vision، ما تدّعيش إنك «شفت» الفريم. استخدم `32_midframes.py`
و`08_safe_check.js` (أرقام)، واطلب من المستخدم عين على `sheet.jpg` مرة واحدة.

## 3) السياق — يغيّر إزاي تتعامل مع فيديو طويل

| سياق الموديل | فيديو ≤ 3 دقائق | 3–15 دقيقة | > 15 دقيقة |
|---|---|---|---|
| ≥ 200k | تفريغ كامل مرة واحدة | `18_long_transcribe` + لخّص | ريلات متعددة |
| 32k–200k | كامل | قسّم لنوافذ، لخّص كل نافذة | ريلات متعددة + لا تقرا النص كله |
| < 32k | لخّص الأسطر أول | نوافذ 3 دقائق | لا تحاول — قسّم لمشاريع |

## 4) الصوت — يغيّر مسار التعليق

| الحالة | الاختيار |
|---|---|
| فيديو فيه كلام | لا تعليق — كابشن فقط (الافتراضي) |
| فيلم موشن | `edge-tts` لو شغّال، وإلا SAPI (`Microsoft Haya/Naayf`) + توقيت تقديري، وإلا **بلا تعليق** |
| صوت المستخدم | `voice.py --own` — أفضل نتيجة دايماً |

## 5) إيه اللي بيتغيّر فعلياً في التشغيل

| القرار | حسب الإجابة |
|---|---|
| عدد المشاهد | طبقة الموديل (§2) |
| المعاينات | طبقة الموديل: ورقة واحدة للرخيص، ورقتين للقوي |
| المراجعة العربية | دايماً وكيل فرعي لو المتاح؛ وإلا المشرف بقراءة بطيئة |
| المراجعة البصرية | vision → وكيل؛ غير كده أرقام + عين المستخدم |
| مسار التثبيت والأوامر | الوكيل (§1) |
| تقسيم التفريغ | السياق (§3) |

## 6) مين ما ينفعش

- **موديل بلا قدرة على تشغيل أدوات** (chat فقط): السكل ما ينفعش — محتاج تنفيذ سكربتات.
- **وكيل بلا terminal**: استخدم نسخة الـ plugin لو موجودة، وإلا ما تقدرش تشغّل ffmpeg.
- **موديل بلا vision + مستخدم مش متاح**: اقبل إن الجودة البصرية أقل، وقولها في التقرير.

## 7) التطبيق

```bash
python scripts/onboard.py new acme --name "Acme" --ai-host opencode --model "claude-opus-4.5" ...
python scripts/onboard.py apply "<work>" acme     # يكتب ai.json كمان
```

`ai.json` = `{"host":"opencode","model":"...","vision":true|false|null,"context":"200k|32k|unknown","notes":""}`.
لو ما عرفتش القدرات، سيبها `null` — السكل ياخد الحذر (أرقام + عين المستخدم).
