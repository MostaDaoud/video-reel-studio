# الهوية — أونبوردنج اختياري (5 دقايق، مرة واحدة)

الهدف: **قبل أي فيديو** تعرف لمين بنتكلم، وبأي لون وخط، وإيه الممنوع.
النتيجة: هوية محفوظة في `~/.config/opencode/brands/<slug>.json` تُستخدم في كل مشروع بعد كده.

## القاعدة الأولى: اسأل، متفرضش

أول ما يوصلك طلب فيديو، **قبل أي سكربت**، اسأل سؤال واحد:

> «قبل ما نبدأ: نجهّز هويتك مرة واحدة (5 دقايق: ألوان، خط، نبرة، ممنوعات)،
> ولا نمشي على هوية محفوظة، ولا نكمّل بالافتراضي ونغيّر بعدين؟»

- **فيه هوية محفوظة؟** اذكر اسمها بجملة: «عندك هوية **مصطفى داود** محفوظة — أمشي عليها؟»
  لو قال أيوه، تخطّى الأونبوردنج كله.
- **جديد؟** كمّل الأسئلة السبعة.
- **«كمّل بالافتراضي»؟** ما تسألش تاني في نفس المشروع. الافتراضي:
  `bg #0B0C0C · ink #F4F2EE · acc #19C3AE · Cairo · capStyle chunk`.
- **مشغول / عايز يبدأ؟** ابدأ الفيديو بالافتراضي، واعرض الهوية **بعد** أول تسليم.

⛔ ممنوع: تبدأ الأونبوردنج من غير ما تسأل، أو تسأل 12 سؤال، أو توقف المشروع عشان الألوان.

**عنده صور أو لوجو؟** استخرج اللوحة من الصور بدل ما تخمّن:

```bash
python scripts/00_theme_refs.py "<work>" --refs "img1.png" "img2.png"
```

## بعد الإجابات

```bash
python scripts/onboard.py new <slug> --name "..." --handle "@..." \
  --audience "..." --tone "..." --cta "..." --avoid "..." \
  --bg "#..." --ink "#..." --acc "#..." --font Cairo --capstyle chunk
python scripts/onboard.py card <slug>          # بطاقة SVG تعرضها له
```

اعرض البطاقة. لو وافق:

```bash
python scripts/onboard.py apply "<work>" <slug>   # theme.json + brand.md
```

بعد كده أكمل بالفيديو — `theme.json` هو مصدر الألوان الوحيد.

## بوابة G-1 (الهوية)

| الشرط | الحد | لو فشل |
|---|---|---|
| ink / bg | ≥ 4.5 (المثالي 7) | اقترح لون نص أغمق/أفتح |
| acc / bg | ≥ 3 | اقترح أكسنت أغمق بدرجة |
| onAcc / acc | ≥ 4.5 | `onboard.py` يحسبها تلقائيًا |
| mut / bg | ≥ 3 | افتح الخافت |
| الخط | من القائمة المدعومة | استبدله بـ Cairo |
| capStyle | chunk · line · word · boxed · karaoke | chunk |

`onboard.py new` يرفض الحفظ لو التباين فاشل، ويطبع الأرقام. لا تتحايل على البوابة بتعديل HEX يدوي في `theme.json`.

## تعديل هوية موجودة

- «غيّر اللون» → `new` بنفس الـ slug (يستبدل) ثم `apply`.
- «هوية تانية» → slug جديد.
- «إيه الهويات اللي عندي؟» → `python scripts/onboard.py list`.
